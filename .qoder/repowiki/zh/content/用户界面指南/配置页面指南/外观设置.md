## 项目结构

## 核心组件

外观设置模块的核心组件包括SwitchBox和Slider等UI控件，它们通过React状态绑定实现即时预览效果。配置项与后端Config单例的同步机制确保了用户界面设置的持久化。

### SwitchBox组件分析

SwitchBox组件用于实现开关功能，通过React状态管理实现即时预览效果。组件支持二次标签显示，提供良好的用户体验。

### Slider组件分析

Slider组件基于MUI Slider实现，支持自定义样式和值标签显示。通过useSliderLogic钩子函数管理滑块状态，实现即时预览和提交更新两种模式。

```mermaid
sequenceDiagram
participant UI as "用户界面"
participant Slider as "Slider组件"
participant Logic as "useSliderLogic"
participant Store as "状态存储"
UI->>Slider : 用户拖动滑块
Slider->>Logic : onchangeFunction(值)
alt 即时更新模式
Logic->>Store : setterFunction(值)
Store->>UI : 更新界面
end
UI->>Slider : 释放滑块
Slider->>Logic : onchangeCommittedFunction(值)
Logic->>Store : setterFunction(值)
Store->>UI : 更新界面
```
